## 策略邏輯
### I. 研究動機
台灣股市常見兩種重要的價格偏離現象：  
1. **價值型機會**（價格被低估，處於築底階段）。

2. **動能型機會**（價格因市場情緒或資金推動而快速擴張）。

傳統單因子策略往往只能捕捉其中一種，容易在市場轉換時失效。本策略的核心想法是：**透過四象限框架同時捕捉這兩種 alpha** 來源，打造一個以多頭為主的系統性台股策略。

以兩個核心維度定義市場狀態：
1. **價格波動度（Volatility）**：衡量市場情緒的劇烈程度

2. **價格擴張程度（Price Expansion/Contraction）**：衡量價格相對於近期基準的偏離方向與力道
 
此設計希望能同時把握「價值回歸」與「趨勢延續」兩種獲利模式，在不同市場階段都能維持較穩健的正報酬，並有效控制下行風險。

### II. 股票池篩選

* **流動性過濾**：僅納入台股市值前 300 大且具備高度流動性之標的。

* **實務考量**：確保模型在實盤操作時具備極高的資金容量(Capacity)，降低滑點（Slippage）對績效的侵蝕，適合法人級資金配置。

* **篩選標準**：  

| 指標類型 | 篩選門檻 (台股環境) | 說明 |
| :--- | :--- | :--- |
| 市值 (Market Cap) | > 100 億 TWD | 剔除小型股、低價轉機股。 |
|日均成交值	|> 5,000 萬 TWD	|確保一般散戶或小規模量化模型進出無礙。|
|日均成交值 (高標準)	|> 1 億 TWD	|適合回測時模擬較低滑價的環境（如法人級別）。|
|成交量 (Volume)	|> 1,000 張	|確保盤中掛單連續，不會出現五檔斷層。|


### III. 四象限邏輯
透過定義市場狀態，決定出場、入場訊號：
* **象限I**：高波動 + 價格擴張（過熱/轉折層級）。
* **象限II**：高波動 + 價格縮減（恐慌性殺盤層級）。
* **象限III**：低波動 + 價格縮減（築底/盤整層級）。
* **象限IV**：低波動 + 價格擴張（穩定趨勢層級）。

## 資料與驗證方法

### I.資料期間與 IS/OOS 切割

- 本策略採用 「近期資料訓練（Model Calibration），長期歷史樣本外驗證（Historical OOS / Stress Test）」的架構：

1. **訓練期（2023–2026）：** 鑑於近年市場微觀結構與波動度轉變，採用近期資料作為訓練集，以確保策略邏輯能精準捕捉「當前市場環境」的 Alpha。

2. **歷史OOS驗證期（2016–2023）：** 將訓練好的策略回推至過去 8 年進行歷史樣本外測試，涵蓋 2020 疫情熔斷與 2022 熊市，確保策略在不同市場循環下皆具備高度穩健性與生存能力。

### II. 參數優化方式
- 使用Grid Search

### III. 使用的驗證手段
1. **Cross-section (Asset) Permutation**
- 把「持倉訊號」隨機分配到不同標的上。

    > **H0​**：策略的優異表現只是剛好隨機選到特定個股。<br>**H1​**：策略的選股規則具備真正的 Alpha。

- 結果：顯著。
![CS_distribution](./equity_curve/asset_permutation.png)

2. **Stationary Bootstrap**
- 保留時間相依結構，重抽連續區塊。

    >**H0​**：策略的優異表現只是剛好對齊特定時間序列。<br>**H1​**：策略的表現明顯優於隨機持倉結構的預測能力。

- 結果：不顯著。
![SB_distribution](./equity_curve/stationary_permutation.png)

## 風險與限制
1. **時間預測能力有限**：Stationary Bootstrap 與時間序列相關檢定顯示，策略在「進出場時間點」上的優勢並不顯著。策略績效對市場路徑較為敏感，若未來報酬序列的時間結構與歷史樣本差異較大，實際表現可能明顯偏離回測結果。
2. **橫截面優勢可能隨市場結構改變而減弱**：Cross-section Permutation 檢定支持策略具備一定的選股／排除能力，但此優勢建立在當前市場的股票相關性、產業輪動與風險溢酬結構上。若市場風格發生長期轉變（例如因子失效、流動性結構改變、或監管環境變化），橫截面 alpha 可能衰退。
3. **樣本外驗證期間有限**：雖然單一或多段 OOS Bootstrap 結果呈現顯著正期望，但樣本外期間仍相對有限，無法完全排除特定市場環境（如特定波動或趨勢階段）帶來的幸運成分。更長時間、更多市場狀態的驗證仍有必要。
4. **參數搜尋與多重檢定風險**：策略開發過程中涉及參數優化，雖已透過 permutation 與 bootstrap 等方法進行檢驗，但仍存在一定程度的資料窺探（data-snooping）風險。實務上應避免頻繁根據最新資料重新優化參數。
5. **交易成本、滑價與流動性限制**：回測結果通常未完全反映真實交易中的衝擊成本、滑價與委託失敗情況。中低頻策略雖換手率相對較低，但在流動性較差的標的或市場壓力期間，實際成本可能顯著高於假設，進而侵蝕淨報酬。
6. **長期樣本仍無法完全排除路徑依賴風險**：策略回測已涵蓋約 10 年資料，且多數子期間呈現正期望報酬。然而 Stationary Bootstrap 結果顯示，績效對特定時間路徑仍有一定敏感度。10 年樣本雖具參考價值，但仍無法涵蓋所有可能的市場結構轉變或極端情境，未來實際表現仍可能偏離歷史結果。
7. **模型風險與黑天鵝事件**：策略依賴歷史統計關係，對於極端市場事件（如流動性瞬間枯竭、政策突發、系統性風險）的防禦能力有限。回測與模擬無法完全涵蓋未來可能出現的新風險因子。
8. **基準與比較的局限性**：策略表現優於部分隨機持倉或簡單基準，但並不保證長期穩定超越大盤或相關指數。投資人應以自身風險承受度與整體資產配置角度評估，而非單獨依賴歷史夏普或淨值曲線。
